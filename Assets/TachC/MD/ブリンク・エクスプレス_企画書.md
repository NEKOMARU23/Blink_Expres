# ブリンク・エクスプレス 企画書

最終更新：2026-10-31

## 概要

『ブリンク・エクスプレス』は、投げたワープビーコンの位置へ瞬間移動し、勢いを保ったまま壁やレールを使って駆け抜ける3Dハイスピードアクション。主人公は配達人で、迫ってくる災害から逃げ切り、ゴール（配達先）に届ける。

操作とルールはWebデモ版で遊んで確かめ、確定した。数値と細かい条件は「ブリンク・エクスプレス_仕様書.md」にまとめている。デモ版：https://claude.ai/artifact/Ckr9sCb7JmMrH2Hag85ifP

## コアメカニクス

核は「ワープ → 少し滑る → 次を投げる」のリズム。ワープするたびに加速し、素早くつなぐほど加速が大きくなる。ただし連打では加速しないので、スケートで滑る時間にも意味がある。

1. 左クリック長押しで照準。世界がスローになり、肩越し視点で放物線と着弾点が見える
2. 離すとビーコンを投げ、何かに当たった瞬間にその位置へワープ
3. 速さを保ったまま、投げた方向へ向きが変わり、ワープの加速が乗る
4. 少し滑ってから1.6秒以内に次を投げるとチェインになり、加速が増える

ワープを中心に、勢いを保ったまま使える移動手段を組み合わせる。どれも速さを減らさず、進む向きだけを変える。

| 移動手段 | どう使うか | 役割 |
| --- | --- | --- |
| ワープ | 照準して投げる | 加速、方向転換、遠くへの移動 |
| スケート | 常に自動で滑る | 72 km/hまで加速。ワープとワープの間をつなぐ |
| ジャンプ | Space | 泥や障害物を越える。96 km/h以上で二段ジャンプ |
| 壁 | 前から当たる／横でジャンプ | 壁のぼり・壁走り・壁ジャンプで高い所や近道へ |
| スライディング | Shift | 倒木の下を速さを保ってくぐる |
| レール（仕掛け） | 触れると乗る | 速さを保って加速しながら近道を滑る |
| キノコ（仕掛け） | 踏む | 高く跳ねて壁や段を越える |

## 速度ルール

スケートだけで出せるのは72 km/hまでで、それより上（最高144 km/h）はワープ・コイン・破壊・レールでしか上がらない。上がった速さは減速要因がない限り保たれる。重力は向きを曲げるだけで、落ちても速さは変わらない。

| 区分 | 要因 |
| --- | --- |
| 加速 | スケート（72 km/hまで） |
| 加速 | ワープ（チェインで増える。連打では加速しない） |
| 加速 | コイン（理想の走行ラインに配置し、道しるべも兼ねる） |
| 加速 | 敵の破壊 |
| 加速 | レールに乗っている間 |
| 減速 | 速度不足で敵に弾かれる |
| 減速 | 後ろ方向キーでブレーキ |
| 減速 | 泥（減速床）を滑る |
| 減速 | 天井に当たる |
| 減速 | 紫の壁や倒木に正面からぶつかる |

高い所から落ちたときの減速は、壁のぼりや壁ジャンプの邪魔をしていたので廃止した。

敵ごとに「壊すのに必要な速度」がある。かたい敵（115 km/h以上）はスケートだけでは壊せず、ワープをつないで加速したときだけ突き破れる。

## 照準とスロー、投げのルール

照準中は世界がスローになり、肩越しの近い視点に切り替わる。放物線を少し横から見られるので、どこに落ちるかが分かる。一人称も試したが、弧を真後ろから見ることになり、見にくかった。

- 投げるには必ず照準が必要。照準中は0.25倍のスロー（完全には止まらない）
- 照準にはゲージを使う。満タンで約6秒狙え、空になると照準もワープもできない
- ゲージはコイン・破壊・時間で回復
- ビーコンは放物線を描く。カメラを上に向けるほど遠くへ届く（水平で約20 m、少し上で約70 m）
- 投げた後は短いクールタイム。ビーコンは同時に1つだけ
- 予測線と着弾点の色で、当たったときの結果を予告する

## 操作方法

キャラは常に前へ滑り、マウスで向けた方向へ自動で曲がる。「見た方向へ走り、見た方向へ投げる」。最初はA/Dで曲がる操作だったが、カメラと体の向きがずれて逆走しやすかったため、この形に変えた。

| 操作 | キーボード＋マウス | コントローラー（予定） |
| --- | --- | --- |
| カメラ・進む向き | マウス | 右スティック |
| 左右に寄せる | A / D | 左スティック左右 |
| ブレーキ | S | 左スティック下 |
| 照準（スロー） | 左クリック長押し | LT長押し |
| ビーコンを投げる | 左クリックを離す | LTを離す |
| 照準キャンセル | 右クリック | RT |
| ジャンプ・壁ジャンプ・レールから降りる | Space | A |
| スライディング | Shift | B |

## 壁・天井・床のルール

壁は「当たる向き」で動きが変わる。どの動きも速さは保ち、速いほど高く登れる。

- **前から当たる：** 真上に壁のぼり。72 km/hなら約22 m登れる。登りきると壁の上に乗る
- **横から当たる（地上）：** 壁に沿って向きが変わるだけ。減速しない
- **横から（壁の横でジャンプ）：** 地面から2 mの高さで壁走り。水平にまっすぐ1.2秒走り、その後は少しずつ下へ曲がる
- **ワープで壁に着弾：** 投げた方向を壁面に沿わせて壁滑走
- **壁ジャンプ（Space）：** 壁を蹴って斜め前上へ。二段ジャンプも復活するので、柱の間をジグザグに進める。壁のぼり中はさらに上へ（1回）
- **逆走しない：** 登れない壁に正面から当たっても跳ね返さず、壁沿いに横へ逃がす
- **天井：** すぐ落ちて減速。低い屋根の区間では「狙いを外すと危ない」

## 目的と評価

一定速度で迫ってくるもの（ステージごとに異なる）から逃げ切り、ゴール地点（配達先）に届けるとクリア。

- 評価はクリアタイムとコインの取得率を組み合わせたランク（S〜C）
- 追ってくるものはスケートの上限より少し遅い一定速度。減速が重なると追いつかれる
- 飲み込まれるとゲームオーバー
- ワープは使えば有利になるもので、ワープなしでも地上ルートでクリアできる（詰み防止）
- ゴールすると自己ベストの走りが記録され、次から半透明のゴーストとして一緒に走る（繰り返し遊ぶ理由になる）

## 世界観とステージ構成

ファンタジー世界の配達人が主人公。会社支給の腕装着型ワープ装置からワープビーコンを発射し、同じく支給品のローラースケート（雪山ではブレード）で駆け抜ける。

| ステージ | 舞台 | 追ってくるもの | 敵 | 見せる要素 |
| --- | --- | --- | --- | --- |
| チュートリアル | 会社の訓練施設 | なし | 訓練用ダミー（わら・木・鉄） | 操作をひとつずつ体験（1〜2分） |
| ステージ1 | 平原 | 暴走する魔物の群れ | スライムや羊っぽいモンスター、岩の魔物 | 全長1500 m・10区間。壁、紫の壁、低い屋根、柱の林、段々畑、三本道、塔と大壁、泥の沼、最後の関門。Webデモ版で実装済み |
| ステージ2 | 雪山 | 雪崩 | 雪だるまやペンギンっぽいモンスター | ブレードで滑りやすく速度が乗る。壁走りと方向転換が重要 |
| ステージ3（余裕があれば） | 火山 | 溶岩流 | 小さな溶岩ゴーレム | 総仕上げ。最後に上限近い速度で巨大な壁を突き破る |

各区間には「安全だけど遅い道」と「技を使う近道」を用意する。平原の区間ごとの内容は仕様書を参照。

敵はポップでかわいい見た目にし、倒すとポンと弾けて星やコインになる演出で爽快感を出す。ステージ3は期限に間に合わなければ削れるようにしておく。

## チュートリアル

会社の訓練施設で、1つずつ覚えて最後にまとめて使う。1〜2分に収める。練習相手は訓練用ダミーで、硬さを敵と同じ3段階（わら・木・鉄）にして素材で硬さを覚えてもらう。

1. 滑走とブレーキ：マウスで曲がり、Sで減速する
2. 照準と投げ：照準でスローになること、上に向けるほど遠くへ飛ぶことを体験
3. チェイン：ワープ後に少し滑ってから投げると加速、連打では加速しない
4. ジャンプとスライディング：泥を跳び越え、倒木をくぐる
5. 壁：前から当たって登る、横で跳んで壁走り、壁ジャンプ
6. 破壊：わら・木・鉄のダミー。速度が足りないと弾かれることも体験
7. 総仕上げ：レールとキノコも入った短いコースを抜ける

トラップや紫の壁など、その他の仕掛けは、本番ステージで初めて出てきたときに画面上部へ短い案内を出す（デモ版で実装済み）。

## 敵

敵は硬さで3段階に分け、見た目の大きさと硬さを一致させて「今の速さで壊せるか」を一目で分かるようにする。

| 硬さ | 必要速度 | 平原 | 雪山 | 火山 |
| --- | --- | --- | --- | --- |
| やわらかい | 低（ほぼいつでも壊せる） | スライム | 小さな雪玉モンスター | 火の玉 |
| ふつう | 中 | 羊っぽいモンスター | ペンギンっぽいモンスター | 小さな溶岩ゴーレム |
| かたい | 高（上限近くが必要） | 大きな岩の魔物 | 大きな雪だるま | 大きな溶岩ゴーレム |

- 行動は敵の種類ごとに固定せず、ステージに配置したあとで個別に設定できるようにする
- 行動の種類：動かない、移動する、プレイヤーから逃げる（候補）
- 体当たりなど、敵からの攻撃はなし

## ステージの仕掛け

仕組みは共通にし、見た目だけステージごとに変える。レールとキノコは加速や近道になる「味方の仕掛け」、それ以外は減速や回り道を生む「邪魔をする仕掛け」。低速になる仕掛けは、減速床（泥）だけを使う（低速の要因が多いと不快になりすぎるため。「触れると大きく減速する接触トラップ」と「一定間隔で出るタイミングトラップ」は使わない）。

| 種類 | 効果 | 平原 | 雪山 | 火山 | デモ版 |
| --- | --- | --- | --- | --- | --- |
| グラインドレール | 触れると乗り、速さを保って加速。ワープでも飛び乗れる | 黄色い手すり | 凍った電線 | トロッコのレール | 実装済み |
| 跳ねるキノコ | 踏むと約10 m跳ねる | 赤いキノコ | 雪のクッション | 噴き出す蒸気 | 実装済み |
| 減速床 | 上を通る間ずっと減速 | ぬかるみ | 深い雪 | 固まりかけの溶岩 | 実装済み |
| 倒木 | スライディングかジャンプで越える低い横棒 | 倒木 | 氷のアーチ | 崩れた石の梁 | 実装済み |
| ワープ妨害面 | ビーコンが当たってもワープ不発。登れない | 魔法のつる壁 | 厚い氷の壁 | 黒曜石の壁 | 実装済み |

雪山と火山の見た目のうち、レール・キノコ・倒木の列は仮案。

## UI

走行中に見る情報は画面中央に集め、それ以外は画面の端に小さく置く。粉砕や減速などは文字を出さず、エフェクトで伝える（細部は実装時に決める）。

| 位置 | 要素 | 内容 |
| --- | --- | --- |
| 中央 | ゲージ・クールタイム・十字 | ゲージは十字を囲む円弧。十字はチェインをつなげる間だけ水色に光る。照準中はすべて消す |
| 中央の下 | チェイン数 | 「CHAIN ×n」「早すぎ：加速なし」 |
| 照準中 | 予測線と着弾点 | 光の点で描いた放物線、着弾点の輪と光の柱。色と短い文言で結果を予告：水色＝着地・壁滑走、緑＝粉砕できる、黄＝速度不足、赤＝ワープ不可、白＝レール、オレンジ＝天井 |
| 照準中・上部 | スロー表示とゲージバー | 中央のゲージの代わりに残量を示す |
| 左下 | 速度メーター | 数値とバー。中・高の硬さとスケート上限に目盛り。上限近くで光り、「二段ジャンプ可」も表示 |
| 右上 | タイム・ベスト・コイン | ランク評価に使う数字と自己ベスト |
| 上部 | 進行バーと案内 | 追ってくるもの・自分・ゴールの位置。初めての仕掛けの案内はその下 |
| 画面全体 | 演出 | 速度で視野角と集中線が変化、照準中は薄い青、追ってくるものが近いと画面の縁が赤くにじむ |

演出はデモ版で実装済み：粉砕の瞬間にわずかに時間を止める、ワープの光の残像、壁走り中のカメラの傾き、効果音と速度に応じた風切り音。粉砕や減速は画面中央に文字を出さず、エフェクトで伝える。

## 技術アピールポイント

面接で「自分で設計・実装した」と語れる処理を、意識して作り込む。

- **状態管理：** 地上・スライディング・空中・壁（のぼり／走り／滑走）・レールをステートマシンで整理する
- **速さを保った向きの変換：** ワープ・ジャンプ・壁・キノコすべてを「速さはそのまま、向きだけ変える」一つの考え方で実装。壁では Vector3.ProjectOnPlane で壁面に投影し、正規化して元の速さを掛け直す
- **当たる向きの判定：** 進行方向と壁の法線の内積で「前から」「横から」を分け、壁のぼりと壁走りを切り替える
- **弾道予測：** 投げる前の予測と実際の弾道を同じ計算で一致させ、着弾先の結果（粉砕できるかなど）まで予告する。薄い壁をすり抜けないよう線分で判定する
- **部分的なスロー：** 世界を遅くしつつ、UI・カメラ操作・ゲージの消費は実時間で動かす
- **ゴースト：** 位置と向きを一定間隔で記録し、補間して再生する
- **調整しやすさ：** 約30個のパラメータを ScriptableObject に切り出す。敵の行動は配置ごとにインスペクターで設定する
- **手触りを試作で詰めた過程：** Webデモ版で遊んでは直すことを繰り返した。「ワープだけで済む」「逆走する」「照準が見にくい」などの問題と、その直し方を面接で語れる（次の節）

## 試作で変えたこと

Webデモ版で遊んで見つかった問題と、その直し方。企画の決定の理由として残す。

| 問題 | 原因 | 直し方 |
| --- | --- | --- |
| 面白くない | ワープは速さを保つだけで、使う理由がなかった | スケートの上限を72 km/hにし、ワープそのもので加速。つなぐとチェイン |
| ワープだけで済む | 連打で加速し続けられた | 直後の連打は加速なし。「ワープ → 少し滑る → 投げる」のリズムに |
| ビーコンが遅い・照準が短い | 放物線が緩く、ゲージの減りが速すぎた | 初速を上げ、ゲージの減りを約1/3に |
| 弾道が直線的でワープできない | ほぼまっすぐ飛んで地面に届かなかった | 重めの放物線にし、カメラの角度で飛距離を調整 |
| 壁の前で足止め、落下で減速 | 高い壁を登ると落下の減速に引っかかった | 落下のルールを廃止。登れない壁は横へ抜ける |
| 横からの壁走りができない | 「壁にぶつかった瞬間」だけで判定していた | 壁の近くでジャンプし、2 mに達したら壁走り |
| 操作しにくく逆走する | A/Dの旋回とマウスのカメラが別々で、正面衝突で跳ね返っていた | マウスで進む向きを決める。正面衝突は横へ逃がす |
| 照準が見にくい | 一人称で弧を真後ろから見ていた。1pxの線が明るい背景に溶けた | 肩越し視点、縁取り付きの光の点、距離で大きくなる着弾点 |
